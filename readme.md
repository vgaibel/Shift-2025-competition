\*\*SHIFT Competition 2025 - Credit Scoring\*\*

Соревнование по кредитному скорингу от ЦФТ ШИФТ



Дан огромный тренировочный датасет, содержащий 1.2 млн строк и всего 2 признака.
Также дан тестовый датасет, содержащий 107 признаков.

Что сделано:

По тренировочному датасету построена и обучена модель классификации (CatBoostClassifier).

Далее посчитаны вероятности для тестового датасета.

Результат (вероятности) взят как таргет для следующей модели (сделан pseudo-labeling).
Проведен EDA и feature engineering (ordinal encoding) для тестового датафрейма.
Построена модель регрессии (CatBoostRegressor), создан цикл кросс-валидации.

Стек: numpy, pandas, seaborn, catboost
